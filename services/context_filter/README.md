# Context Filter — сервис семантической фильтрации статей

Сервис принимает список статей и контекст (ключевые слова/фразы), векторизует их через `embedder`, вычисляет косинусное сходство и возвращает только релевантные статьи. Используется для семантически направленного парсинга.

## API

### POST /filter

Принимает статьи и контекст, возвращает отфильтрованные статьи.

**Запрос:**
```json
{
  "user_id": "admin",
  "context": "искусственный интеллект в медицине",
  "threshold": 0.6,
  "articles": [...]
}

**Ответ:**
{
  "total_received": 10,
  "total_passed": 6,
  "total_filtered": 4,
  "articles": [...],
  "scores": {"article_id": 0.82, ...}
}
