# Reporter — сервис генерации HTML-отчётов

Сервис принимает результаты анализа (JSON от `analyzer`), строит интерактивные графики с помощью `plotly` и сохраняет HTML-отчёт в папку `reports/{user_id}/`. Отчёт содержит визуализацию дрифта, кластеров и сместившихся тем. Предусмотрена заглушка для будущей интеграции с YandexGPT.

## Установка и запуск локально

### Требования
- Python 3.11+
- Результат от `analyzer` (JSON) для передачи в запросе

### Шаги
1. Клонировать репозиторий.
2. Создать виртуальное окружение и активировать:
   ```bash
   python -m venv venv
   source venv/bin/activate  # или venv\Scripts\activate для Windows
Установить зависимости:

bash
pip install -r services/reporter/requirements.txt
Запустить сервис:

bash
python -m services.reporter.src.main
По умолчанию сервер запускается на порту 8005.

Переменные окружения
REPORTS_ROOT — корневая папка для сохранения HTML-отчётов (по умолчанию ./data/reports)

PLOTLY_TEMPLATE — шаблон оформления графиков (по умолчанию plotly_white)

PORT — порт для FastAPI (по умолчанию 8005)

API
POST /generate
Принимает результат анализа (analysis_result) и user_id, генерирует HTML-отчёт и возвращает ссылку на него.

Запрос:

json
{
  "user_id": "test_user",
  "analysis_result": {
    "drift_score": 0.75,
    "shifted_topics": [
      {
        "old_terms": ["ИИ", "этика"],
        "new_terms": ["ИИ", "агенты"]
      }
    ],
    "cluster_details": {
      "current_week": {
        "clusters": {
          "cluster_0": {
            "size": 10,
            "terms": ["ИИ", "роботы"]
          }
        },
        "total_samples": 10
      },
      "previous_week": {
        "clusters": {
          "cluster_0": {
            "size": 8,
            "terms": ["ИИ", "этика"]
          }
        },
        "total_samples": 8
      }
    }
  }
}
Ответ:

json
{
  "status": "ok",
  "report_url": "/reports/test_user/report_2026-07-25_13-05-01.html",
  "text_summary": "Заглушка: текстовое описание трендов будет добавлено позже."
}
GET /reports/{user_id}/{filename}
Отдаёт HTML-файл отчёта. Используется для просмотра в браузере.

GET /health
Проверка работоспособности сервиса.

Логика работы
Приём данных – сервис получает JSON от analyzer.

Генерация графиков – строятся:

Спидометр дрифта (показывает значение drift_score в процентах).

Визуализация кластеров (сейчас заглушка, в будущем – 2D-проекция UMAP).

Таблица сместившихся тем – отображает старые и новые термины для каждого сдвига.

Сохранение – итоговый HTML-файл сохраняется в reports/user_{user_id}/ с уникальным именем (включает дату и время).

Возврат ссылки – клиент получает относительный путь к отчёту, который можно открыть в браузере.

Интеграция с другими сервисами
Вход: JSON от analyzer (передаётся в теле запроса).

Выход: HTML-файл, доступный по ссылке.

В будущем планируется интеграция с YandexGPT для генерации текстового резюме (замена заглушки).

Беклог (дальнейшие улучшения)
Визуализация
Реализовать реальную визуализацию кластеров (передавать координаты UMAP из analyzer и рисовать scatter plot).

Добавить графики временных рядов (изменение дрифта по неделям).

Интерпретация
Интеграция с YandexGPT (или другой LLM) для генерации человекочитаемого описания трендов.

Поддержка нескольких языков (русский, английский).

Функциональность
Возможность отправки отчёта по email.

Кастомизация шаблонов (брендирование, логотипы).

Экспорт в PDF (через weasyprint или wkhtmltopdf).

Безопасность
Добавить JWT-авторизацию (проверка токена через user_manager).

Используемые технологии
FastAPI – веб-фреймворк

Plotly – интерактивная визуализация

Pydantic – валидация данных

Numpy / Pandas – обработка данных (для будущих расширений)
