# Embedder — сервис векторизации текстов

Сервис принимает по REST массив статей, разбивает текст на перекрывающиеся чанки, вычисляет эмбеддинги с помощью модели `all-MiniLM-L6-v2`, сохраняет результат в Parquet-файл и возвращает путь к нему. Работает синхронно, использует CPU-версию PyTorch. Для прототипа векторы сохраняются в общую папку, в будущем планируется переход на сервис `storage`.

## Установка и запуск локально

### Требования
- Python 3.11+
- Модель `all-MiniLM-L6-v2` (скачивается автоматически при первом запуске или указывается локальный путь)

### Шаги
1. Клонировать репозиторий.
2. Создать виртуальное окружение и активировать:
   ```bash
   python -m venv venv
   source venv/bin/activate  # или venv\Scripts\activate для Windows
Установить зависимости:

bash
pip install -r services/embedder/requirements.txt
(Опционально) Если вы хотите использовать локальную копию модели, скачайте её и укажите путь в settings.py или через переменную окружения MODEL_NAME.

Запустить сервис:

bash
python -m services.embedder.src.main
По умолчанию сервер запускается на порту 8002.

Переменные окружения
MODEL_NAME — путь к модели или имя на Hugging Face (по умолчанию models/all-MiniLM-L6-v2)

VECTORS_ROOT — корневая папка для сохранения Parquet-файлов (по умолчанию ./data/vectors)

CHUNK_SIZE — максимальное количество слов в чанке (по умолчанию 256)

CHUNK_OVERLAP — перекрытие между чанками (по умолчанию 32)

PORT — порт для FastAPI (по умолчанию 8002)

API
POST /embed
Принимает массив статей, вычисляет эмбеддинги для каждого чанка и сохраняет результат в Parquet-файл.

Запрос:

json
{
  "user_id": "test_user",
  "articles": [
    {
      "id": "article_123",
      "title": "Заголовок статьи",
      "text": "Полный текст статьи...",
      "source": "lenta.ru",
      "published_at": "2026-07-24T00:00:00"
    }
  ]
}
Ответ:

json
{
  "status": "ok",
  "vectors_file": "/app/data/vectors/user_test_user/2026-07-24.parquet",
  "chunk_count": 456
}
GET /health
Проверка работоспособности сервиса.

Интеграция с ingestor
ingestor после парсинга статей вызывает embedder по эндпоинту /embed, передавая массив статей. embedder возвращает путь к Parquet-файлу с векторами. В текущей версии embedder пишет файлы напрямую в общую папку, которая монтируется в оба контейнера. В будущем планируется переход на асинхронную очередь и сервис storage для централизованного управления данными.

Поддержка других моделей эмбеддингов (например, intfloat/multilingual-e5-large).

Оптимизация чанкинга с учётом семантических границ (предложения, абзацы).

Кеширование эмбеддингов для часто встречающихся текстов.

Безопасность
Добавить JWT-авторизацию (проверка токена через user_manager).

Используемые технологии
FastAPI — веб-фреймворк

sentence-transformers — библиотека для работы с эмбеддингами

PyTorch (CPU-версия) — бэкенд для модели

Pydantic — валидация данных

PyArrow / Pandas — работа с Parquet-файлами
