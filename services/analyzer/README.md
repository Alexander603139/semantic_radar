# Analyzer — сервис кластеризации и детекции дрифта

Сервис загружает векторы (Parquet-файлы) пользователя за указанные периоды, выполняет кластеризацию с использованием UMAP и HDBSCAN, вычисляет дрейф тем (Wasserstein Distance) и возвращает аналитический отчёт в JSON. Используется для выявления изменений в тематике новостных потоков.

## Установка и запуск локально

### Требования
- Python 3.11+
- Наличие Parquet-файлов с векторами (создаются сервисом `embedder`)

### Шаги
1. Клонировать репозиторий.
2. Создать виртуальное окружение и активировать:
   ```bash
   python -m venv venv
   source venv/bin/activate  # или venv\Scripts\activate для Windows
Установить зависимости:

bash
pip install -r services/analyzer/requirements.txt
Запустить сервис:

bash
python -m services.analyzer.src.main
По умолчанию сервер запускается на порту 8004.

Переменные окружения
VECTORS_ROOT — корневая папка с Parquet-файлами (по умолчанию ./data/vectors)

CLUSTERS_ROOT — папка для сохранения промежуточных результатов (по умолчанию ./data/clusters)

UMAP_N_COMPONENTS — размерность после UMAP (по умолчанию 5)

HDBSCAN_MIN_CLUSTER_SIZE — минимальный размер кластера (по умолчанию 5)

PORT — порт для FastAPI (по умолчанию 8004)

API

Логика работы
Загрузка данных – сервис сканирует папку VECTORS_ROOT/user_{user_id}/ и загружает Parquet-файлы за указанные периоды (текущая и предыдущая недели).

Кластеризация – векторы стандартизируются, затем размерность снижается с помощью UMAP, после чего применяется HDBSCAN для выделения кластеров. Для каждого кластера извлекаются топ-термины (на основе частоты слов в текстах).

Дрифт – вычисляется Wasserstein Distance между распределениями векторов текущей и предыдущей недели. Чем выше значение, тем сильнее изменилась тематическая структура.

Сместившиеся темы – сопоставляются кластеры разных недель и фиксируются изменения в терминах.

Интеграция с другими сервисами
Вход: Parquet-файлы от embedder (хранятся в общей папке).

Выход: JSON, который может быть передан в reporter для генерации HTML-отчёта.

В будущем планируется переход на получение данных через сервис storage по API.

Беклог (дальнейшие улучшения)
Алгоритмы
Улучшить сопоставление кластеров для более точного поиска сместившихся тем (например, на основе центроидов или пересечения терминов).

Внедрить многомерную версию Earth Mover's Distance для более точного дрифта.

Оптимизировать UMAP/HDBSCAN для больших объёмов данных (использовать umap-learn с n_jobs).
